SAFESPACE — 5-PAGE HTML/CSS PROTOTYPE

Pages:
1. index.html — Home
2. about.html — About the issue and proposed system
3. report.html — Front-end-only demonstration form
4. support.html — Support, privacy and safeguarding
5. study-hub.html — Offline academic collaboration concept
styles.css — shared responsive styling
assets/ — user-provided images

HOW TO VIEW:
Extract the ZIP, then open index.html in a browser. All pages are linked through the navigation bar.

IMPORTANT:
This is a static front-end prototype. The report form does not send, store, or protect real reports. It generates a temporary demo code in the browser only. A real deployment needs a secure backend/local server, authentication and role-based access, tested encryption, safeguarding policies, trained counselors, institutional approvals and an agreed referral protocol.

The UNESCO image was supplied as a visual reference; this prototype is not an official UNESCO website and does not claim UNESCO endorsement.
